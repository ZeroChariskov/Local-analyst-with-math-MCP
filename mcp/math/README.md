# Titan Math MCP

This is a local stdio MCP server. It does not open a network port and does
not read or write project files.

Tools:

- `calculator`: safe scientific arithmetic with roots, powers, logarithms,
  trigonometry, hyperbolic functions, rounding, combinatorics, and floating
  point helpers, special functions, and complex literals.
- `solve_equation`: symbolic equations using a restricted SymPy namespace.
- `unit_convert`: physical unit conversion.

Install dependencies with `pip install -r requirements.txt`, then register
the server in OpenCode using the example configuration.
