# Local-analyst-math-MCP
This is a Local-analyst based on llama.cpp, I deployed a qwen 3.8 27b Q4 on my TITAN RTX(with a laptop and a graphic card dock), and tailscale gateway for other devices(e.g.phones,Another Laptop etc..) to use local qwen as subagent or just chat.I also put a math mcp to make sure qwen won't make caculation mistakes(running on gateway as MCP client).Works with GPT 5.6 Luna.
